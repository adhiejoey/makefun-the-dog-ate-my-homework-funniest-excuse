A one-line excuse from a dog caught eating the homework: told to "show your work," the dog obliges literally — teeth first, stomach second — and then, completely unrepentant, grades the homework itself with an F for flavor. The program writes that single line to `/output/entry.txt` for the make.fun judge to compare head to head against the other entries.
